# Chat Commands

Chat commands let viewers interact with factions and contribute hype.

## Typical commands
- `!join <faction>` — join a faction
- `!switch <faction>` — change faction
- `!hype <amount>` — add hype to your faction (if enabled)

> Exact command names can be customized in the dashboard.

## Safety and cooldowns
To avoid spam or abuse, commands often include:
- cooldown per user
- maximum allowed delta
- mod/broadcaster bypass rules

If chat is “too strong”:
- increase cooldown
- lower max delta
- require a minimum interval between hype grants
