# Using the Dashboard UI

The **Streamer Dashboard** is where you control everything about Chat Factions.

## Dashboard Sections

### 📊 Meters
Shows live faction hype levels.
- Updates in real time
- Drives overlay visuals
- Used by all overlays

### 🎨 Overlays
Manage your active overlay:
- Select a layout
- Configure visual settings
- Enable or disable overlays
- Adjust performance options

### 👥 Factions
Create and manage factions:
- Name and color each faction
- View hype totals
- Reset or rebalance if needed

### ⚙️ Settings
General configuration:
- Plan tier status
- Streamer preferences
- Feature toggles

---

## How Changes Work
Most changes apply **instantly**:
- Overlay config updates are live
- No OBS refresh required
- No stream restart required

If something doesn’t update:
- Refresh the OBS browser source
- Or reload the dashboard page
