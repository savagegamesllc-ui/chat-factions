# Using the Dashboard UI

The **Streamer Dashboard** is the control center for Chat Factions.  
Everything — overlays, factions, chat behavior, and hype — is configured here.

You do **not** need to restart OBS or your stream when making most changes.

---

## Dashboard Sections

### Dashboard
The main landing page.
Here you’ll find:
- Your OBS overlay URL
- An optional live preview
- Current plan status (FREE or PRO)
- General system status and summaries

This page is where you’ll usually copy your overlay URL for OBS.

---

### Layouts
Layouts control *how your overlay looks*.

From here you can:
- Select which overlay is active
- Adjust visual and performance settings
- Enable or disable specific layouts

Most visual tuning happens here.

---

### Factions
Factions are teams that viewers join in chat.

On this page you can:
- Create or rename factions
- Assign faction colors
- Enable or disable factions
- Reset or rebalance faction meters (if enabled)

---

### Meters
Meters represent **live hype values**.

This page shows:
- Current hype per faction
- Real-time updates from chat and events

Overlays read directly from these meters, so changes here should be visible immediately.

---

### Chat
The Chat section controls how viewers interact.

Here you configure:
- Chat commands
- Cooldowns
- Safety limits
- Moderator or broadcaster bypass rules

This is where you fine-tune how powerful chat interactions are.

---

### Event API
An advanced feature for external integrations.

This allows:
- Games
- Bots
- Automation tools

to trigger hype events without using chat.

---

### Billing
Shows your plan tier and manages upgrades.

FREE users can always access FREE overlays.  
PRO unlocks additional overlays and configuration depth.

---

## When changes apply
Most changes:
- Apply immediately
- Do not require OBS refresh
- Do not require a stream restart

If something doesn’t update:
- Refresh the OBS Browser Source
- Reload the dashboard page
