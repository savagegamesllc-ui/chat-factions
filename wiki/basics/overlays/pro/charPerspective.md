Chat Perspective

Live chat messages appear directly on screen as animated text, transforming viewer reactions into a visual element that moves and evolves during active moments.

Overview

Chat Perspective displays the exact text of the streamer’s chat as animated typography layered over the stream. Messages enter, move, and fade based on the selected presentation style, creating effects such as cinematic crawls, drifting text, waves, or orbiting motion. The overlay is most impactful during active chat moments when multiple messages are visible at once.

Hype Behavior

Low hype behavior
Chat messages appear at a steady pace, with calm motion and limited visual intensity.

Medium hype behavior
Text movement becomes more noticeable, with increased motion speed and more simultaneous messages on screen.

High / spike behavior
Chat activity accelerates, causing messages to move faster and appear more dynamically, emphasizing moments of peak audience engagement.

Faction Interaction

This overlay does not use faction dominance, blending, or per-faction visual regions. Factions do not directly alter colors or layout beyond contributing to overall hype levels that affect motion intensity.

Configuration Options

Mode
Selects how chat text is presented, including cinematic crawl, angled wall, flat scroll, floating drift, wave motion, or orbiting motion.

Maximum Messages
Controls how many chat messages can be visible at the same time.

Message Lifetime
Determines how long each message remains on screen before fading out.

Font Family
Sets the typeface used for chat text.

Font Size
Adjusts the size of chat messages.

Line Spacing
Controls vertical spacing between messages.

Text Color
Sets the primary color of chat text.

Outline Color
Sets the color of the text outline for readability.

Outline Width
Controls the thickness of the text outline.

Tilt Angle
Adjusts the perspective tilt used in cinematic and angled modes.

Scroll Speed
Controls how quickly messages move across the screen.

Float Sway Amount
Adjusts side-to-side motion in floating and wave styles.

Wave Amplitude
Controls the height of wave motion in wave mode.

Orbit Radius
Sets how far messages travel from the center in orbit mode.

Performance Notes

This overlay limits the number of active messages on screen and fades out older entries to maintain stable performance during high chat activity.
