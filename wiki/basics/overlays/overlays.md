# Overlays (Hub)

Overlays are visual effects displayed on stream that react to hype and faction meters.

## Quick start
1. Pick an overlay in **Layouts**
2. Configure it (optional)
3. Add the overlay URL to OBS (Browser Source)
4. Watch it react to chat + events

## FREE vs PRO overlays
- **FREE** overlays are designed to be lightweight and simple to run.
- **PRO** overlays unlock advanced visuals, richer reactions, and more tuning controls.

See: [PRO vs FREE](pro-vs-free)

## Common overlay settings
Most overlays include some mix of these:

### Placement
Where the visuals “live” on screen:
- edges / frame
- bottom bias
- top-center focal (avatar-friendly)

### Mix mode
How faction colors combine:
- weighted blend
- winner

### Intensity
Master multiplier for effect strength.
If an overlay is overwhelming, reduce this first.

### Performance knobs
Controls that protect your frame rate:
- FPS cap
- particle max
- spawn cap per frame
- render scale (offscreen rendering)
